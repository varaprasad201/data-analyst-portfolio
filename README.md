# Sales Performance Analysis

## Overview
Analyzed retail sales data to identify trends, top-performing products, and revenue patterns across different regions.

## Key Findings
- 25% increase in sales during Q4
- Electronics category generated 40% of total revenue
- West region outperformed other regions by 15%

## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Jupyter Notebook
- Data Cleaning & EDA

## Dataset
Mock retail sales data (10,000 transactions)

## How to Run
1. Clone this repository
2. Install requirements: `pip install -r requirements.txt`
3. Open `notebooks/sales_analysis.ipynb`
